# alialinaghi72.github.io

فایل‌های سایت شخصی. همه را در ریشهٔ مخزن قرار دهید:

- `index.html` — کل سایت (تک‌فایل، دوزبانه)
- `og.png` — تصویر پیش‌نمایش برای اشتراک‌گذاری در شبکه‌های اجتماعی
- `favicon.ico`, `icon-512.png`, `apple-touch-icon.png` — آیکون‌ها
- `robots.txt` — اجازهٔ ایندکس و معرفی نقشهٔ سایت
- `sitemap.xml` — نقشهٔ سایت برای گوگل

پس از بارگذاری:
1. در Google Search Console دامنه را ثبت و `sitemap.xml` را معرفی کنید.
2. همین کار را در Bing Webmaster Tools انجام دهید.
3. نشانی سایت را در پروفایل لینکدین (بخش Contact info و About) قرار دهید.
